# Daftar dependensi untuk Hugging Face Space (SDK gradio).
#
# KENAPA ISINYA DIDUPLIKASI DARI backend/requirements.txt, bukan `-r` ke sana:
# pada tahap pip install, HF TIDAK menyalin isi repo. Yang dilakukan cuma
# me-mount satu file ini sendirian ke /tmp/requirements.txt:
#
#   RUN --mount=target=/tmp/requirements.txt,source=requirements.txt \
#       pip install --no-cache-dir -r /tmp/requirements.txt ...
#
# Akibatnya `-r backend/requirements.txt` di-resolve jadi /tmp/backend/requirements.txt
# yang tidak ada, dan build mati dengan "Could not open requirements file".
# Jadi daftarnya memang harus utuh di sini.
#
# Supaya tidak diam-diam melenceng dari backend/requirements.txt, ada
# backend/tests/test_requirements_sync.py yang jadi merah kalau keduanya beda.
# Kalau menambah dependensi: ubah backend/requirements.txt, lalu samakan di sini.
#
# `gradio`, `spaces`, `torch`, dan `uvicorn` TIDAK ditulis di sini: HF menambahkannya
# sendiri di perintah pip yang sama sesuai `sdk_version` di frontmatter README.md.
